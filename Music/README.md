# Music

Put the music for matches here (`.mp3`, `.ogg`, `.wav`, `.flac` or `.m4a`).
Every file in this folder plays, shuffled and looped, while you are in a match.

No music is included in the source code because of copyright. When you build the
app yourself, the files in this folder get bundled into the executable. You can also
put a `Music/` folder next to a built executable to use other songs without rebuilding.
